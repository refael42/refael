# store/ — הכול לחנויות

| קובץ | מה יש בו |
|---|---|
| `release-guide.md` | **להתחיל מכאן.** מדריך העלאה צעד אחרי צעד, ומה רק אתה יכול לעשות |
| `listing-he.md`, `listing-en.md` | שם, כותרת משנה, תיאורים, מילות מפתח (`npm run store:check` בודק אורכים) |
| `products.md` | ארבעת מוצרי היהלומים: מזהים, מחירים, שמות |
| `privacy-policy.md` / `.html` | מדיניות פרטיות בעברית ובאנגלית (ה-HTML מוכן לאירוח) |
| `questionnaires.md` | תשובות לשאלונים: פרטיות, דירוג גיל, בטיחות נתונים |
| `screenshots/` | צילומי מסך בגדלים של כל חנות, בעברית ובאנגלית |

**מה עוד חסר (רק אתה):** שם סופי, מזהה סופי, אייפד כן/לא, מייל תמיכה, חשבונות Apple/Google/Expo.

# חיבור וואטסאפ ל-SiteFlow

כשהוואטסאפ מחובר, הקבלן לא צריך את האפליקציה:
- כל הודעה בצ'אט שלו עם מנהל הפרויקט נשלחת אליו לוואטסאפ. זה כולל משימה שהשתחררה, משימה ששויכה אליו, בקשה לתמונה, אישור או דחייה של דיווח, סיכום הבוקר והודעות שמנהל הפרויקט כותב לו.
- מה שהוא עונה בוואטסאפ מגיע לצ'אט באפליקציה. ה-AI מציע מה לעשות עם ההודעה, ומנהל הפרויקט מאשר.
- כשהקבלן כותב "סיימתי ריצוף בדירה 4", המערכת מבקשת ממנו תמונה. התמונה שהוא שולח הופכת לדיווח סיום שממתין לאישור. אם הוא שולח עוד תמונות מיד אחריה, הן מצטרפות לאותו דיווח.
- כדי להפסיק לקבל הודעות הקבלן שולח "הסר", וכדי לחזור הוא שולח "הצטרף".

## מספר אחד לכל המערכת

הקבלנים עונים מהוואטסאפ הרגיל שלהם ולא צריכים מספר חדש. צריך רק מספר אחד לחברה, שאסור שיהיה פעיל עליו וואטסאפ.
אפשר להתחיל לבדוק עם **מספר הבדיקה החינמי של Meta**, שמאפשר לשלוח לעד 5 מספרים מאושרים. בהמשך מחליפים למספר אמיתי בהגדרה אחת.

## שלבים

1. **developers.facebook.com** ← My Apps ← Create App ← סוג **Business** ← מוסיפים את המוצר **WhatsApp**.
2. ב-**WhatsApp ← API Setup**:
   - **Phone number ID**: זה הערך של `WHATSAPP_PHONE_NUMBER_ID`.
   - **To**: מוסיפים את המספרים של מי שבודק (אתה, עידו). זה נדרש רק כשעובדים עם מספר הבדיקה.
3. **טוקן קבוע**: ב-business.facebook.com ← Settings ← Users ← **System users** ← Add (Admin) ← Generate token עם ההרשאות `whatsapp_business_messaging` ו-`whatsapp_business_management`. הטוקן הוא הערך של `WHATSAPP_TOKEN`. הטוקן הזמני מ-API Setup פג אחרי 24 שעות.
4. **App secret**: בהגדרות האפליקציה ← App settings ← Basic ← **App secret**. זה הערך של `WHATSAPP_APP_SECRET`.
5. **Verify token**: ממציאים מילה סודית כלשהי. זה הערך של `WHATSAPP_VERIFY_TOKEN`.
6. מכניסים את 4 הערכים ב-**Vercel ← Settings ← Environment Variables** ועושים Redeploy.
7. **Webhook**: ב-WhatsApp ← Configuration ← Edit:
   - Callback URL: הכתובת שמופיעה באפליקציה בהגדרות ← קבלנים ← כרטיס "וואטסאפ" (`https://<האתר>/api/whatsapp`)
   - Verify token: אותה מילה מסעיף 5.
   - אחרי Verify and save לוחצים Manage ומסמנים **messages**.
8. **תבנית הודעה**: ב-WhatsApp Manager ← Message templates ← Create:
   - שם: `siteflow_update`, קטגוריה **Utility**, שפה **Hebrew**
   - גוף ההודעה:
     ```
     עדכון מ-SiteFlow:
     {{1}}

     אפשר לענות כאן.
     ```
   - האישור לוקח בדרך כלל כמה דקות עד יום.

## למה צריך תבנית

וואטסאפ מאפשר לכתוב לקבלן הודעה חופשית רק במשך 24 שעות מההודעה האחרונה שהוא שלח. מחוץ לחלון הזה ההודעה נשלחת דרך התבנית המאושרת, ו-SiteFlow בוחר בעצמו בין השתיים.
אם יוצאת מחוץ לחלון תמונה או קובץ, הקבלן מקבל הודעה שמחכה לו קובץ. הקובץ עצמו יישלח אליו אחרי שיענה.

## עלות

Meta גובה על הודעות שהמערכת יוזמת (תבניות). המחיר לכל הודעה קטן ומשתנה לפי מדינה. תשובות בתוך חלון ה-24 שעות לא עולות כסף.

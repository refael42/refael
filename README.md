# שף טייקון — Chef Tycoon

An isometric idle restaurant tycoon (landscape): you are the manager of a small Tel Aviv
restaurant that grows into an empire. Expo (React Native) + Skia; runs on Android, iOS and web.

## איך מריצים (Windows)

**פעם אחת בלבד:**
1. מתקינים **Node.js** מ-https://nodejs.org (הכפתור הירוק **LTS**, ואז Next עד הסוף).
2. בטלפון: מתקינים **Expo Go** מחנות האפליקציות.
3. מורידים את המשחק: בעמוד https://github.com/refael42/refael/tree/claude/restaurant-tycoon-game-aye10l
   לוחצים על הכפתור הירוק **Code** ← **Download ZIP**, ואז קליק ימני על הקובץ ← **Extract All** (חילוץ).

**בכל פעם שרוצים לשחק:**
1. נכנסים לתיקייה שחולצה ולוחצים פעמיים על **start-windows.bat**.
   (אם Windows מזהיר — "More info" ← "Run anyway".)
2. נפתח חלון שחור, ואחרי כמה דקות (בפעם הראשונה) מופיע ברקוד (QR).
3. בטלפון: Expo Go ← **Scan QR code** ← סורקים. הטלפון והמחשב צריכים להיות על **אותה רשת Wi-Fi**.
4. או בדפדפן במחשב: לוחצים על המקש **w** בחלון השחור.

לגרסה חדשה: מורידים שוב את ה-ZIP (או `git pull`) ומריצים שוב את start-windows.bat.

**למפתחים:** `npm run check` (בדיקות), `npm run balance` (דוח קצב התקדמות), `npm run web` (דפדפן),
`node scripts/make-icons.mjs` (מצייר מחדש את אייקון האפליקציה), `node scripts/make-sounds.mjs` (מייצר מחדש את הצלילים).

אחרי התקנת חבילות חדשות — לעצור את השרת (Ctrl+C) ולהפעיל מחדש, אחרת Metro "שוכח" קבצים.

## בנייה לטלפון אנדרואיד (גרסת בדיקה)
פעם אחת במחשב: `npm install -g eas-cli` ואז `eas login`. אחר כך לחיצה כפולה על `build-android-test.bat`:
הבנייה רצה בענן של Expo (15–30 דקות), ובסוף יש קישור וקוד QR להתקנה בטלפון. פרטים ב-`store/release-guide.md`.
בגרסת הבדיקה יש בהגדרות "בדיקות" (כסף לבדיקה, אוטובוס, עומס); בגרסת החנות הן לא מופיעות.
עדכון מהיר לשחקנים אחרי שהמשחק בחנות: לחיצה כפולה על `publish-update.bat` (ראו שלב 11 במדריך).

## איך משחקים

- **בפעם הראשונה:** מסך פתיחה, "ברוכים הבאים" (בוחרים שפה), שם המנהל/ת ושם המסעדה (אפשר
  להשאיר ריק או ללחוץ על הקובייה 🎲), שלושה כרטיסי "איך משחקים", ואז הדרכה: **יד לבנה**
  מראה על מה ללחוץ, והודעה למעלה אומרת מה לעשות. אפשר תמיד "לדלג על ההדרכה".
- **למעלה:** מטבעות (משמאל), היום (באמצע, שמש/ירח ופס שמתמלא עד סוף היום), דירוג הכוכבים
  (מימין). מטבעות שעפים למונה נספרים כשהם נוחתים. "x3 רצף" מתחת למטבעות = תשלומים ברצף = טיפים גדולים יותר.
- **⭐ רמת שף (כמו ב-Hay Day):** הכוכב הזהוב למעלה, בין המטבעות ליום, עם המספר של הרמה ופס ירוק של ניסיון. ניסיון מקבלים
  מכל לקוח שמשלם (ועוד נקודה על 5 כוכבים), משלוח, שדרוג, גיוס, שלב, ביקור של מבקר וכוכב במדריך, ובניין חדש. כל רמה נותנת
  יהלומים ונקודת כישרון (ומרמה 4 גם מטבעות), וכל 5 רמות **תיבה** עם הכנסה כפולה ל-5 דקות ו-3 נקודות כישרון. לחיצה על הכוכב: מה תקבלו ברמה הבאה, מה נפתח
  ברמות הבאות ואיך צוברים ניסיון. הרמה שלכם עוברת לכל בניין ולכל סניף.
- **📖 תפריטים וקינוחים:** ליד המארחת בכניסה יש עמדת תפריטים. האורחים פותחים את התפריט בידיים, קוראים ומדפדפים, ואז מזמינים.
  אחרי הארוחה חלק מהם מבקשים את **תפריט הקינוחים** הוורוד, בוחרים, והקינוח מופיע בבועה מעליהם. מלצר פנוי מסדר אותו בפס ומביא,
  או **לוחצים על האורח** והוא מגיע מיד. הקינוח נכנס לחשבון. 10 קינוחים נפתחים לפי רמת השף: מלבי (רמה 6), סופגנייה (9), בקלאווה (12),
  מוס שוקולד (15), עוגת גבינה (18), טירמיסו (21), קרם ברולה (24), סופלה שוקולד (27), וופל בלגי (30) וכנאפה (34).
- **גוררים** עם האצבע כדי לזוז במפה, **צובטים** עם שתי אצבעות כדי לעשות זום (בדפדפן: גלגלת העכבר).
- לקוח בתור עם בועת כיסא → **לוחצים עליו** כדי להושיב.
- מנה מוכנה על הדלפק (קופצת ומנצנצת) → **לוחצים עליה** כדי להגיש.
- שולחן מלוכלך עם ספוג → **לוחצים** כדי לנקות (לחיצות נוספות = מהר יותר).
- מתחילים רק עם **טבח/ית**. את כל השאר מגייסים: מלצר/ית (מביא/ה מנות ומפנה), שוטף/ת כלים,
  מארח/ת (מקבל/ת את הלקוחות בדלת, מלווה אותם לשולחן ומגיש/ה להם תפריט), מנקה. אפשר תמיד לעזור לצוות: ללחוץ על מנה מוכנה, על שולחן
  מלוכלך, או על הכיור (שטיפה מהירה).
- **אירועים 🎁 (מתחת לכוכבים):** כפתור אחד במקום שורת כפתורים. המספר האדום = כמה דברים מחכים (ביקורות,
  פרסי פסטיבל, מבצע). לחיצה פותחת שורה עם המבצעים, הפסטיבל, מבצע הבזק, הביקורות ומדריך השף.
- **המטבח לא עומד בקצב 🍳:** כשהזמנות מחכות ומלצרים פנויים, הודעה מעל הכפתורים הגדולים אומרת מה יעזור (עוד
  טבח / "עמדת טבח נוספת" / כיריים מהירות יותר) ולחיצה פותחת את המסך הנכון. ✕ מסתיר ל-10 דקות.
- **שלט OPEN / CLOSED (למעלה, בין היום לדירוג):** כמו השלט על דלת של חנות. לחיצה מסובבת אותו וסוגרת את המסעדה
  לאורחים חדשים. מי שבפנים מסיים לאכול, והתור הולך הביתה בלי לכעוס. כשהיא ריקה, הודעה מתחת לשלט אומרת שאפשר לשדרג
  ולסדר בנחת. לחיצה נוספת פותחת. כשחוזרים למשחק היא תמיד פתוחה.
- **מטבעות ביהלומים 🪙:** בחנות ← "מטבעות": ערימה (10 דק' הכנסה), שק (30 דק') וכד זהב (שעתיים). הכמות
  מוצגת במטבעות וגדלה ככל שהמסעדה מרוויחה יותר.
- **מלצרים פנויים** (אין צלחת להגיש ואין שולחן לפנות) עוברים בין השולחנות עם כוס מים ומחזירים ללקוחות
  שמחכים קצת סבלנות. אחד תמיד נשאר ליד הפס. הרבה מלצרים עומדים? המטבח הוא הצוואר: עוד טבחים, או
  לשנות תפקיד למלצר (בכרטיס העובד/ת) לטבח.
- נגמרו הצלחות הנקיות → הטבח/ית נעצר/ת ומופיעה בועה של צלחת עם איקס מעל ערימת הצלחות.
- **📦 ספקים ומחסן (כפתור "מחסן" למטה):** כל מנה שהטבח מתחיל לוקחת יחידה אחת מהמחסן: **ירקות** (צ׳יפס, סלט, פלאפל),
  **בשר ודגים** (המבורגר, שווארמה, שניצל, סושי, סטייק...) או **מזווה** (חומוס, פיצה, גלידה, עוגה, פאד תאי). משאית ירוקה של הספק
  מגיעה לבד כל דקה וקצת, עוצרת ברחוב משמאל לדלת, מורידה ארגזים וממלאת את המחסן. המצרכים עולים בערך 5% מההכנסה, והסכום יורד לבד
  מהקופה בזמן שהכסף נכנס (אי אפשר לקבל אותם בחינם גם כשמוציאים הכל). לכל מצרך בוחרים ספק: **שוק העיר** (זול ב-40%, המנות -5%),
  **ספק ותיק** (רגיל) או **חווה אורגנית** (מהביסטרו: יקר, המנות +12%, והמבקר של המדריך שם לב). נגמר מצרך? המנות שלו מחכות למשאית,
  הטבחים עוברים למנות אחרות, ואפשר להזמין **משלוח דחוף** (משאית אדומה, עולה יותר). שדרוגים במקרר: **מחסן** (יותר מקום) ו**חוזה ספקים**
  (משאית מהר יותר וזול יותר).
- **👑 כרטיס עונה (בכפתור האירועים 🎁):** עונה של 4 שבועות. כל יום 3 משימות חדשות (מתחלפות בחצות), וכל שבוע עוד 5 משימות
  שנשארות עד סוף העונה: להגיש מנות חמות, להכין נכון בקשות מיוחדות, קינוחים, משקאות, משלוחים, 5 כוכבים ועוד (רק משימות שאפשר
  לעשות במסעדה שלכם). משימה שהושלמה נותנת ניסיון (XP). כל 180 XP = דרגה, ויש 30 דרגות. בכל דרגה יש פרס: מטבעות, יהלומים, סיבובים
  בגלגל, בוסט או נקודות כישרון. בדרגה 30 מקבלים **מדליה**: כל החשבונות +2% לתמיד, גם בסניפים הבאים. **כרטיס זהב** (₪19.90 או 600 יהלומים)
  מוסיף פרס גדול יותר בכל דרגה, גם על דרגות שכבר עברתם, ובסוף מדליית זהב (+3%). פרסים שלא נלקחו מחולקים לבד כשהעונה נגמרת.
- **🔥 מנה חמה:** מנה שמחכה על הפס מתקררת. בשניות הראשונות יוצאים ממנה אדים, והיא נמכרת ביותר (+5%). אם היא
  עומדת יותר מדי מופיע עליה פתית שלג כחול: היא נמכרת בפחות, והאורח כועס וכותב על זה. **מנורות חימום** (שדרוג
  בפס, נפתח מכיריים רמה 10) שומרות אותה חמה יותר זמן. עוד מלצרים = פחות מנות קרות.
- **🔪 הכנות מראש:** טבח בלי הזמנה לא עומד: הוא חותך ירקות ליד העמדה שלו. על קרש בראש הפס מופיעה קערה לכל הכנה מוכנה
  (בהתחלה עד 3). מנה שמתחילה עם הכנה מוכנה מתבשלת 35% מהר יותר, אז מלאי מלא עוזר בשעת עומס. **מקרר הכנות** (שדרוג
  במקרר, נפתח ממקרר רמה 5) נותן יותר מקום ומהירות.
- **🌶️ בקשות מיוחדות:** חלק מהאורחים מבקשים את המנה **חריפה**, **טבעונית** או **ללא גלוטן** (סמל קטן ליד בועת המנה
  ועל הפתק). זה לוקח לטבח קצת יותר זמן, ולפעמים הוא טועה (טבח טוב טועה פחות). **הבודק** בפס תופס מנה שהוכנה לא נכון
  ושולח אותה להכנה מחדש. מנה לא נכונה שמגיעה לאורח = אורח מאוד כועס וביקורת רעה. מנה שהוכנה נכון = טיפ גדול וביקורת טובה.
  **לוח בקשות מיוחדות** (שדרוג בפס) = פחות טעויות וטיפ גדול יותר.
- **מועמדים לעבודה:** מגיעים לדלת עם בועת קורות חיים. לוחצים על המועמד/ת (או על הכפתור הסגול
  "צוות" → "מועמדים") → כרטיס עם כישורים, תכונות ושכר יומי. אפשר: **לגייס** (דמי חתימה),
  **יום ניסיון** (חינם, מחליטים בסוף היום), **להציע פחות** (פעם אחת, אולי יסכימו) או לוותר.
- **מזג אוויר:** לכל יום יש מזג אוויר (האייקון ליד "יום" למעלה: שמש ☀️, עננים ⛅, גשם 🌧️). שלושת
  הימים הראשונים תמיד שמשיים. ביום גשום נכנסים קצת פחות לקוחות, אבל מי שבפנים סבלני יותר.
- **יום עבודה = 2 דקות.** השעון באמצע למעלה (שמש/ירח) מראה כמה נשאר; בערב נהיה חשוך והפנסים
  נדלקים. בסוף כל יום משלמים משכורות. אין כסף → מורל יורד, ואחרי יומיים בלי שכר עובדים עוזבים.
- **כרטיס עובד/ת:** לוחצים על עובד/ת במפה או ברשימה → מורל, אנרגיה, רמה. **בונוס** (מורל ↑),
  **הכשרה** (רמה ↑), **לנזוף** (עובדים מהר יותר לזמן קצר, מורל ↓), **להחליף תפקיד**, **לפטר**
  (שתי לחיצות). עובדים טובים מבקשים העלאה — כרטיס למעלה עם "לאשר" / "לסרב".
- **⭐ כישרונות לעובדים:** בכרטיס של כל עובד/ת יש 6 כישרונות, כל אחד עד רמה 5: **זריזות** (עובדים 4% מהר יותר לכל רמה),
  **מצב רוח** (המורל יורד 15% פחות), **כושר** (האנרגיה נגמרת 12% לאט יותר), **מקצועיות** (מנות ומשקאות טובים 3% יותר),
  **חן** (טיפים וסבלנות של אורחים) ו**נאמנות** (משכורת נמוכה 4% לכל רמה, פחות בקשות העלאה; ברמה 5 לא מתפטרים בגלל מורל).
  רמה 1 עולה נקודה, רמה 2 שתיים וכן הלאה. כמה רמות עובד/ת יכול/ה להחזיק = הרמה שלו/ה + 1. **נקודות כישרון** מקבלים
  מגלגל המזל (המשבצת הזהובה, +3), מכל רמת שף (+1, ובתיבה +3), מכל רמת מסעדה (+1), מהמתנה היומית (+1, ביום 7: +5),
  מהמדריך (צלחת ראשונה +2, כל כוכב ראשון +5), או בחנות ← "עובדי כוכב" (5 ב-💎25, 20 ב-💎80). כוכב סגול על כפתור "צוות" =
  יש נקודות לחלק. פיטורין מחזירים את כל הנקודות, איפוס (💎10) מחזיר אותן, ובסניף חדש הנקודות של הצוות הקודם חוזרות.
- **עוד טבחים:** "שדרוגים" → "מטבח" → "עמדת טבח נוספת" (350) = מקום לטבח/ית נוסף/ת. כל התחנות כבר במטבח.
- **שדרוגים:** חץ ירוק מעל משהו = אפשר לשדרג אותו. לוחצים על הכיריים / הכיור / שולחן / דלפק
  ההגשה וכו׳ → נפתח חלון השדרוג שלו (והוא מקבל מסגרת זוהרת). הכפתור הירוק "שדרוגים" למטה
  פותח את כל השדרוגים לפי קטגוריות.
- **שולחן חדש:** המקום המקווקו עם "+" — לוחצים עליו וקונים שולחן נוסף (הוא נכנס למקום הבא בסידור של המסעדה).
- **🪑 סוגי שולחנות ומיקום חופשי:** הכפתור הכתום "בנייה" ← "שולחן חדש" ← בוחרים סוג: **עגול**, **מרובע**, **ארוך**
  (שני משבצות, 6 מקומות כשהוא משפחתי) או **ספות** (מהביסטרו). המשבצות הירוקות מראות איפה הוא נכנס ← לוחצים על משבצת
  (רואים את השולחן שקוף) ← "להציב". **להזיז שולחן:** במצב בנייה לוחצים על שולחן שאין בו אורחים ← לוחצים על משבצת ירוקה
  (בחינם; אפשר גם לבחור לו סוג אחר ואז ללחוץ על המשבצת שלו). שולחן לא נכנס למקום שחוסם מעבר — המשחק בודק.

  אקווריום, פסל זהב, מזרקה מהארמון, פסנתר כנף מהאימפריה). **להזיז קישוט:** במצב בנייה לוחצים על
  קישוט שכבר עומד, ואז על משבצת ירוקה — והוא עובר לשם. לחיצה ליד משבצת (לא בדיוק עליה) בוחרת את הקרובה → לוחצים על משבצת ירוקה → "להציב". לכל קישוט יש מסלול שדרוגים משלו:
  לוחצים עליו במפה. אי אפשר לחסום שולחן, תור או מעבר — המשחק בודק.
- **רמה 100:** הכיריים, הכיור, המקרר והשלט ברחוב גדלים ומקבלים דגם חדש (מנדף נחושת, מדיח
  תעשייתי, מקרר ענק, שלט חוצות).
- **יחצ״ן/ית (מהביסטרו):** עובד/ת בחולצה צהובה וכובע שעומד/ת על המדרכה ומחלק/ת פליירים לעוברים
  ושבים. חלק מהם (יותר אצל יחצ״ן עם קסם גבוה) מסתובבים ונכנסים לאכול. מקבלים מקום ליחצ״ן אחד בביסטרו,
  ועוד מקומות בבניינים הגדולים (עד 3).
- **אחמ"ש (מנהל/ת משמרת):** מגיע/ה כמועמד/ת כשיש 2 מלצרים וצוות של 5. עומד/ת בחליפה אדומה עם לוח בקצה
  הדלפק, קורא/ת למלצרים (קודם ללקוח הכי חסר סבלנות), המלצרים מהירים יותר ומתעייפים פחות, ומדי כמה
  שניות ניגש/ת ללקוח עצבני ומרגיע/ה אותו (לב ❤).
- **טורבו 🔥:** הכפתור העגול ליד גלגל השיניים — **מחזיקים** אותו והצוות עובד הרבה יותר מהר כל עוד יש
  טעינה (המסך זוהר בכתום). כל שנייה מורידה קצת מצב רוח לעובדים. משחררים — נטען מחדש.
- **מסך השדרוגים:** נפתח על "★ הכי משתלם" (מה שהכי שווה לקנות עכשיו), יש **חיפוש** וכפתור **"אפשר לקנות"**.
- **מועמדים:** התג "👍 מומלץ" מסמן את המועמד/ת הכי משתלם/ת לגייס.
- **💎 יהלומים וחנות:** מתחת למטבעות יש מונה יהלומים — לוחצים עליו (או על ה-+) ונפתחת **החנות**:
  חבילות יהלומים (**הדגמה — לא נגבה כסף**), מאיצים (הכנסה פי 2 / פי 5, קפיצה בזמן), **עובדי כוכב**
  (רמה 6, כישורים מעולים) ושדרוגים לתמיד. יהלומים מקבלים גם בכל עלייה ברמת המסעדה.
- **משימות 📜:** הכפתור ליד גלגל השיניים (מראה את רמת המסעדה). בכל רמה יש 3 משימות (לשדרג משהו,
  לשרת לקוחות, לגייס, להרוויח...). משימה שהושלמה ← **"לקחת"** = מטבעות. כשלוקחים את כולן — **עולים רמה**
  (בונוס, קונפטי וכרטיס "עליתם רמה!"). המשימות ממשיכות בלי סוף.
- **שירות טוב = יותר כסף:** כל לקוח שמשלם נותן ציון 1–5 כוכבים (קופצים מעל הראש) לפי כמה חיכה.
  5 כוכבים = חשבון מלא, פחות כוכבים = משלמים פחות. לפעמים לקוח כותב **ביקורת**: 4–5 כוכבים = בונוס
  מטבעות, ו-5 כוכבים גם 🔥 "Trending" = יותר לקוחות לכמה שניות.
- **💬 עמוד הביקורות:** הכפתור 💬 מימין למעלה, מתחת לכוכבים (מראה כמה מטבעות מחכים, או את הממוצע). שם
  רואים כל ביקורת: כוכבים, שם, מה כתבו, ומתחת **ציון לאוכל, לשירות ולאווירה** (כמו באתרי ביקורות). יש **358 ביקורות שונות**
  ב-20 סוגים, לפי מה שקרה באמת: על המנה, על המלצרים, על המארחת, על העיצוב, על המחיר, על הקינוח (מי שאכל), על המשקאות
  (מי ששתה), דייטים, משפחות, תיירים, מבקר אוכל מקצועי, ביקורות "חצי-חצי" של 3 כוכבים — וגם **רעות** (חיכו הרבה לאוכל,
  תור ארוך, שירותים מלוכלכים, יצאו בלי לאכול). לשוניות "הכול" / "טובות" / "רעות". **"לקחת"** בשורה, או **"לקחת הכול"**
  למעלה = הבונוס נכנס לקופה. נשמרות 40 האחרונות (בונוס שלא נלקח לא הולך לאיבוד: הוא נכנס כשהביקורת הישנה יוצאת).
- **🎡 גלגל המזל:** נפתח **בביסטרו** (עד אז הכפתור אפור עם מנעול; לחיצה עליו אומרת מתי נפתח). הכפתור עם הגלגל הקטן ליד כפתור השלב. כשכתוב עליו **"חינם"** — לוחצים, ואז על
  **"סובבו"** (באמצע הגלגל או הכפתור הירוק). הפרסים: מטבעות (5 עד 60 דקות של הכנסה), יהלומים, הכנסה
  כפולה ל-10 דקות, **3 נקודות כישרון** או **ג׳קפוט** (שעתיים של הכנסה + 25 יהלומים). כשהגלגל עוצר — **"לקחת!"**. סיבוב חינם
  כל 4 שעות, סיבוב שמור על כל שלב שמסיימים, ועוד סיבובים ב-💎20.
- **🌳 המפה:** מעבר לכביש יש מדרכה שנייה עם אנשים שמטיילים, מכוניות חונות, ופארק גדול — כיכר עם מזרקה,
  ספסלים, ערוגות פרחים, דוכני שוק ומגלשה. מסביב למסעדה יש עוד שטח עם עצים מכל הצדדים. גוררים את המפה כדי
  לראות הכול (ובזום החוצה רואים את כל השכונה).
- **👑 כתר הטעמים:** בניין שמיני, אחרי גלקסיית הטעמים — פרקט זהב, עוד מטבח, עוד שולחנות ועוד עובדים.
- **🛵 משלוחים:** נפתחים **בביסטרו**. מגייסים **שליח/ה** (כפתור "צוות" ← מועמדים; בביסטרו יש מקום לאחד, ובכל
  בניין גדול יותר עוד). מרגע שיש שליח מגיעות הזמנות משלוח: הטבח מבשל אותן כרגיל אבל אורז **בשקית** (בלי צלחת), השקית
  מחכה על הדלפק, השליח נכנס, לוקח אותה, יוצא לקטנוע שליד המדרכה ונוסע — ואחרי כמה שניות חוזר עם הכסף
  (משלוח עולה **35% יותר** + טיפ). שליח ברמה 3 ומעלה לוקח **שתי שקיות** בכל נסיעה. משלוח שאף אחד לא לקח
  במשך 2 דקות מתבטל (והדירוג יורד קצת). כדאי לשים לב: משלוחים ולקוחות במסעדה חולקים את אותם טבחים.
- **🔓 דברים שנפתחים כשהמסעדה גדלה:** ביסטרו — גלגל המזל, משלוחים, יחצ״ן. מסעדה גדולה — שולחנות משפחתיים,
  צ׳קר, פיצה, ישיבה על הבר. ארמון האוכל — עמדת אריזה, סושי. אחר כך סטייק, עוגה ולובסטר. כשבונים בניין חדש מופיע כרטיס
  "נפתח עכשיו", ובשדרוג "בניין" רואים בשורה "ייפתח:" מה הבניין הבא יפתח.
- **💎 דרגות לעובדים:** לכל מועמד/ת יש דרגה: **רגיל** (אפור), **נדיר** (כחול), **אפי** (סגול), **אגדי** (זהב).
  רואים אותה בכרטיס ובטבעת צבעונית מתחת לרגליים במפה. נדירים מתחילים ברמה גבוהה יותר, עם יכולות טובות יותר,
  לומדים מהר יותר ומבקשים קצת יותר שכר. בבניינים גדולים יותר מגיעים יותר נדירים. עובדי כוכב מהחנות = אגדיים.
- **🍽️ שולחן משפחתי (4 מקומות):** מהמסעדה הגדולה. לוחצים על שולחן → "שולחן משפחתי" — שולחן זוגי הופך
  לשולחן מרובע עם 4 כיסאות (אם יושבים בו, הוא מתחלף כשהם קמים). מגיעות **משפחות של 3–4** (לרוב עם ילדים).
- **🍕 מנות חדשות:** פיצה, סושי, סטייק, עוגה ולובסטר — כל אחת נפתחת עם בניין ("שדרוגים" → "תפריט").
- **✅ צ׳קר:** מהמסעדה הגדולה מגייסים צ׳קר/ית. עומד/ת בראש דלפק ההגשה ובודק/ת כל מנה; מנה שנבדקה מקבלת **וי
  ירוק** ונמכרת ביותר.
- **📦 עמדת אריזה:** מארמון האוכל — דלפק אריזה בפינה הקדמית של המטבח, עם **חלון טייק-אווי** (סוכך מפוספס).
  מגייסים **אורז/ת**: הולך/ת לדלפק ההגשה, לוקח/ת את קופסת האוכל, חוזר/ת לעמדה, אורז/ת בשקית (רואים את זה
  קורה, עם עיגול התקדמות) ומניח/ה על אדן החלון. השליח מגיע לחלון מבחוץ והשקית עוברת לו ביד — הוא כבר לא
  נכנס למסעדה, והקטנועים חונים ליד החלון. משלוח ארוז = **+10%**.
  לעמדה יש **פס משלוחים** ו**מקרר שתייה** אדום משלה: כשיש אורזים, הטבחים שמים את המשלוחים על הפס הקטן ליד
  העמדה (הדלפק הגדול נשאר לאולם). האורז/ת לוקח/ת את הקופסה מהפס, פותח/ת את המקרר ולוקח/ת פחית, ואורז/ת את שניהם.
- **🛵 שדרוגי משלוחים:** "שדרוגים" ← **"משלוחים"** (או לוחצים על קטנוע / על עמדת האריזה): **צי שליחים** (עוד מקום
  לשליח בכל רמה), **קטנועים מהירים** (נסיעות קצרות יותר, ארגז חדש לקטנוע ברמות 10/25/50), **אפליקציית משלוחים**
  (כל משלוח משלם יותר), **עמדת אריזה** (מארמון האוכל: אורזים מהר יותר ודלפק חדש).
- **📅 ימי השבוע:** ליד מספר היום למעלה כתוב איזה יום בשבוע (המשחק מתחיל ביום ראשון). **שישי ושבת = סוף
  שבוע:** בדרך כלל 30%–60% יותר לקוחות, דגלים צבעוניים על חזית המסעדה והודעה "סוף שבוע!". ימים רגילים —
  כמות רגילה (ביום חמישי בערב כבר קצת יותר עמוס).
- **הדמויות חיות:** קופצות משמחה (לב), נבהלות (סימן קריאה), רוקעות ומנידות ראש כשהן כועסות, נשענות קדימה
  בהליכה, מתיישבות בתנועה רכה, מסתכלות מסביב, רוקעות ברגל בתור כשנגמרת הסבלנות, ובשולחן חלק מהלקוחות
  בודקים את הטלפון עד שהאוכל מגיע. מלצרים הולכים בזהירות עם מגש מלא, ומארחות מנופפות. חלק מהזוגות הם
  **הורה וילד** (ילד = דמות קטנה).
- **📊 נתוני המסעדה:** גלגל השיניים ← "נתוני המסעדה" — כמה לקוחות הוגשו, כמה הרווחתם, דירוג, רצף, גביעים ועוד.
- **✨ מה חדש:** אחרי עדכון, כרטיס אחד מראה מה נוסף ("הבנתי!" סוגר אותו).
- **🎪 פסטיבל:** הכרטיס הקטן מימין למעלה (מתחת לכוכבים) — כל פסטיבל נמשך **3 ימים** ויש לו מנה משלו
  (צ׳יפס, המבורגר, פלאפל, שווארמה, חומוס, גלידה — כל פעם אחרת). כל לקוח שמשלם = נקודה, מנת הפסטיבל =
  נקודה נוספת, 5 כוכבים = עוד נקודה, VIP = 10, תיירים = כפול. הנקודות פותחות 8 פרסים בדרך (מטבעות,
  יהלומים, סיבובים בגלגל, הכנסה כפולה); כשכתוב **"פרס!"** בירוק — לוחצים על הכרטיס ואז **"לקחת"**.
  הפרס האחרון הוא **גביע הפסטיבל** — יש אותו **רק בפסטיבל הזה**, והוא נותן **+10% על כל חשבון לתמיד**
  (גם בסניפים הבאים). הגביעים עומדים על המדרכה ליד הדלת. בשעות האחרונות הכרטיס נהיה אדום. נקודות
  נאספות רק כשמשחקים (לא כשהמשחק סגור). פרס שהגעתם אליו ולא לקחתם — נכנס לבד כשהפסטיבל נגמר.
- **⚡ מבצע בזק:** הכרטיס האדום מתחת לפסטיבל (גם בראש החנות): פריט אחד מהחנות בהנחה גדולה (עד 50%) ל-3
  שעות בלבד, ואפשר לקנות אותו פעם אחת. שעון עוצר מראה כמה זמן נשאר.
- **🚌 אוטובוס תיירים:** מדי פעם (כל 7–12 דקות משחק) אוטובוס עוצר מול המסעדה וקבוצה של 5–8 תיירים
  יורדת ונכנסת לתור — תושיבו אותם מהר! תיירים משלמים **+50%** ומביאים נקודות פסטיבל כפולות.
- **צלילים, מוזיקה ורטט:** מטבעות, הגשה, שדרוג, פטיש של צוות בנייה, פנפרה ברמה חדשה, קופה ביום
  משכורת ומוזיקת בית קפה רגועה. הטלפון רוטט קצת בלחיצה על כפתורים ובהישגים גדולים. בדפדפן הצלילים
  מתחילים אחרי הלחיצה הראשונה. אפשר לכבות כל אחד בנפרד בגלגל השיניים.
- **גלגל השיניים** (למטה בצד): שפה, צלילים / מוזיקה / רטט, השמות (עריכה), איך משחקים, מונה FPS, גלריית דמויות, בדיקת עומס,
  **כסף לבדיקה** (כל לחיצה = פי 1000 מטבעות), **להזמין אוטובוס תיירים** (מגיע מיד), איפוס התקדמות (מתחיל הכול מחדש, כולל מסכי הפתיחה וההדרכה).
- המשחק נשמר לבד. כשחוזרים אחרי יותר מדקה — מסך "ברוכים השבים" (אחרי מסך הפתיחה) עם הכסף שהצוות הרוויח: המספר עולה פעם אחת עד הסכום.

## Project layout

| Folder | What lives there |
|--------|------------------|
| `src/sim` | Pure, deterministic simulation: customers, kitchen, A*, commands (no UI imports) |
| `src/data` | Data tables: map, dishes, customer types, economy, looks |
| `src/render` | Skia renderer: procedural low-poly art → atlas, isometric drawing, FX, camera; HUD/splash icons |
| `src/ui` | React Native screen, HUD, opening animation, first-run screens, tutorial, panels |
| `src/store` | Zustand stores |
| `src/i18n` | Hebrew + English strings |
| `tests` | Vitest unit tests |
| `store` | App Store / Google Play material: texts (he/en), privacy policy, products, questionnaires, release guide in Hebrew, screenshots (`npm run store:check` checks the text lengths) |

See `PROGRESS.md` for milestones, decisions and known issues.
